# Учебный проект: Администрирование Linux (Ubuntu 20.04 Server)

**Цель:** Освоение базовых навыков системного администрирования Linux на виртуальной машине (VirtualBox) без графического интерфейса.  

---

## Выполненные задачи  

### 1. Установка ОС
- Установил Ubuntu 20.04 Server LTS без графического интерфейса.  
- Проверил версию системы с помощью `cat /etc/issue`.  

### 2. Создание пользователей
- Создал нового пользователя.  
- Добавил его в группу `adm`.  
- Проверил изменения через `cat /etc/passwd`.  

### 3. Настройка сети
- Изменил hostname системы.  
- Установил правильный часовой пояс.  
- Определил сетевые интерфейсы и IP, полученный от DHCP.  
- Настроил статический IP, шлюз и DNS через netplan.  
- Проверил доступность сети пингом до 1.1.1.1 и ya.ru.  

### 4. Обновление ОС
- Обновил системные пакеты (`apt update && apt upgrade`).  
- Убедился в отсутствии новых обновлений.  

### 5. Использование sudo
- Разрешил созданному пользователю выполнять команды с `sudo`.  
- Сменил hostname от имени нового пользователя.  

### 6. Настройка службы времени
- Настроил автоматическую синхронизацию времени через NTP.  
- Проверил часовой пояс и синхронизацию (`timedatectl`).  

### 7. Работа с текстовыми редакторами
- Установил и использовал редакторы VIM, Nano, Joe.  
- Создал и редактировал файлы, сохраняя и выходя без сохранения.  
- Освоил поиск и замену текста в каждом редакторе.  

### 8. Установка и настройка SSHD
- Установил и включил SSH-сервер.  
- Настроил запуск при старте системы.  
- Изменил порт на 2022.  
- Проверил работу сервиса через `ps` и `netstat`.  

### 9. Использование утилит top и htop
- Установил и запустил `top` и `htop`.  
- Определил uptime, нагрузку CPU и RAM, количество процессов.  
- В `htop` использовал сортировку, фильтрацию и поиск процессов.  

### 10. Работа с дисками
- Получил информацию о дисках через `fdisk -l`.  
- Определил размер, количество секторов и swap.  

### 11. Мониторинг дискового пространства
- Использовал `df` и `df -Th` для проверки разделов и ФС.  
- С помощью `du` определил размеры папок `/home`, `/var`, `/var/log`.  
- Установил и использовал `ncdu` для удобного анализа места.  

### 12. Работа с системными журналами
- Просмотрел `dmesg`, `syslog`, `auth.log`.  
- Определил время последней авторизации.  
- Перезапустил SSHd и нашёл запись о рестарте в логах.  

### 13. Планировщик CRON
- Настроил выполнение команды `uptime` каждые 2 минуты.  
- Проверил логи выполнения.  
- Просмотрел и очистил список заданий.  

---

## Полученные навыки
- Установка и администрирование Ubuntu Server.  
- Управление пользователями и правами.  
- Настройка сети (DHCP, статическая конфигурация, DNS).  
- Работа с системными сервисами (SSH, NTP).  
- Использование ключевых утилит администратора (`top`, `htop`, `df`, `du`, `ncdu`, `fdisk`).  
- Работа с системными журналами.  
- Использование планировщика CRON.  
- Практика в работе с текстовыми редакторами в консоли (Vim, Nano, Joe).
